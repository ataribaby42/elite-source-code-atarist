# I.F.F. Unit replacement

## Behaviour

Both enhanced platforms replace the Energy Bomb with the **Zerion Sentinel
I.F.F. Unit**. Equip displays this full manufacturer/model name in its existing
40-column description row; equipment lists use **I.F.F. Unit**.

Without the unit, every otherwise visible scanner contact is steady yellow.
The usual range, invisibility, cockpit and `no_radar` checks still apply.
With the unit, the existing role colours and hostile-contact flashing return.
The separate navigation compass is unchanged.

Pressing **I** without the unit clears any pending identification and displays
`I.F.F. Not Installed`, with the same error sound as unavailable ECM. With the
unit, the existing identification and green aiming indicator work normally.
Missile arming, locking and firing do not require I.F.F.; **U** still cancels
pending identification and missile arming. Radio messages and their addressing
also remain independent of the unit.

The former **Tab** action has been removed, together with the bomb destruction
routine, its dedicated sound implementation and its electrical discharge
renderer. Ordinary explosions, ECM and other effects retain their existing
behaviour. The Amiga build no longer generates or links the custom bomb sample.
Historical source and supplied original disk/archive files are untouched.

## Equipment and saved games

I.F.F. reuses equipment slot 8 (word offset 16 in the equipment record). The
record remains 17 words and the commander file remains 256 bytes. The saved
word at byte offset 34 consequently reads as I.F.F.; an older commander carrying
an Energy Bomb receives an installed I.F.F. Unit. No other equipment moves.

Default new commanders start without I.F.F. The existing debug loadout retains
an installed item in the replaced slot. The unit is permanent equipment,
occupies one tonne, and has the existing shop availability, duplicate-purchase
restriction, affordability/space checks and half-price resale rules. A ship
exchange requires selling it with the other ordinary equipment.

The unchanged hull-category prices are:

| Hulls | I.F.F. price |
| --- | ---: |
| Cobra Mk III | 2,500 Cr |
| Adder, Gecko, Cobra Mk I | 1,250 Cr |
| Fer-de-Lance, Asp Mk II | 2,500 Cr |
| Python, Boa, Anaconda | 1,875 Cr |
| Moray, Sidewinder, Krait, Mamba | 938 Cr |

The user-supplied I.F.F. artwork was already present in both `gfx` and `gfx_alt`
on both platforms, and is used without modification.

## Verification

`tests/native_iff.py` executes the linked 68000 routines on each platform.
It checks purchase and sale for all 13 hulls, duplicate/failed transactions,
equipment mass, identification controls and messages, missile independence,
inactive Tab, saved-slot compatibility, and actual scanner pixels with and
without I.F.F. across all eight contact classes, both blink phases and both
screen buffers. It also checks background restoration and existing scanner
visibility exclusions.

The existing targeting suite now explicitly installs I.F.F. before testing
identification. The obsolete bomb-specific combat/sample tests were removed;
ordinary combat and mission scenarios remain. The Amiga original-effect test
mapping follows the removal of the bomb event from the sound-event table.

Runtime reports and build logs are stored under each platform's `build/iff-qa`,
with additional Amiga regressions under `build/iff-regression-qa`.
Emulators use private executables, configurations and disk copies on verified
hidden Windows desktops. Only standard `ELITE` and `ELITE_ALT` distributions
are built for each platform.

Completed results:

- Atari ST: both distributions built; 1,218 native scenarios passed. Unit-test
  discovery ran 35 tests, with the historical-artwork identity check skipped
  because the artwork is customized.
- Amiga: both distributions built; 1,252 native scenarios passed. Unit-test
  discovery ran 36 tests, with the same expected artwork-identity skip.
- Both platforms passed the 158 new I.F.F. scenarios and existing targeting,
  player-ship equipment, AI combat, Thargoid/Thargon, mission-objective, spawn,
  missile, docking, radio, cloaking, condition and Special Cargo regressions.
- Amiga also passed all 27 original-effect comparisons against Elite 2.0 ADF,
  plus pulse-audio and incoming-hit/communication-audio tests. Atari's impact
  and communication-audio tests passed, and sound-event table ordering was
  checked after removing the bomb entry.
- Linked binaries contain none of the removed bomb handlers or sample labels.
  Final distribution hashes and the user's equipment artwork were checked
  again after testing; runtime tests used private disk copies.
