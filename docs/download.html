Release assets include the packaged game images. This website is a guide; it does not run an emulator or bundle a Kickstart or TOS ROM.

Amiga

ImageArtwork
ELITE.ADFOriginal cockpit and UI
ELITE_ALT.ADFGrey alternate cockpit and UI

The framed 68000 version targets 1 MB RAM, including 512 KB Chip RAM plus 512 KB expansion RAM, and works with Kickstart 1.3. Start with this version on an A500-class machine.

  1. Download and unpack the release.
  2. In an Amiga emulator, select a suitable machine and attach the ADF as its boot floppy. Use your own system ROM.
  3. Boot the disk. On real hardware, use compatible floppy emulation or transfer it to a disk.
  4. For hard-drive use, retain the complete game directory and start ELITE.

Accelerated or high-resolution versions need a suitably faster machine and display. Select an image for your actual setup rather than the largest resolution by default.

The enhanced Atari ST version targets a 68000 machine with 1 MB RAM. Use the low-resolution colour display.

  1. Download and unpack the release.
  2. Attach the ST image to a compatible emulator, using your own TOS ROM, or transfer the files to suitable media for a real ST.
  3. Run ELITE.TOS. Keep the supporting game files alongside the executable.

The separately preserved original version retains historical gameplay. It is distinct from the enhanced game documented on this website.
