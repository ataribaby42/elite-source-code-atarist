07

Collision damage matrix

These are the implemented asymmetric collision rules. The proposed common player/AI combat model has not been implemented.

Base = 8 + floor(target current health / 32) → size adjustment → round(base × 7 / player strength)

Two or more classes larger: fatal. One class larger: add 4. Equal class: unchanged. One class smaller: integer half. Two or more smaller: integer quarter. Constrictor contact is always fatal.

Each recharge event adds 1 energy, capped at 96. For ordinary hulls without an energy unit, shields gain 1 each only when energy is full after that update. Counting rules

  • Player damage: floor((incoming × 7 + floor(strength / 2)) / strength).
  • A hit drains only the struck shield; overflow drains the shared energy bank. Zero energy is lethal.
  • AI missile hits to kill: ceil(current health / 60). Zero health is lethal for missile damage.
  • AI laser hits to kill: floor(current health / laser damage) + 1. Laser destruction requires underflow.
  • No recovery, ECM interception, misses, cloaking phases, other attackers or equipment energy drain are included in the numeric hit counts.
  • Game-loop timing, firing cadence and regeneration mean these counts are not time-to-kill measurements.

Verification scope

This HTML is a source-derived snapshot. Data extraction checks parity between both platforms and uses the actual integer rounding and kill thresholds. The previously completed missile/Cougar change also passed eight native scenarios per platform in isolated emulators. No gameplay code was changed to create this page.
